# Сетевая игра

`dist/online.js` реализует настоящее прямое соединение двух браузеров через WebRTC. Библиотека PeerJS **1.5.5** включена локально в `dist/vendor/peerjs.min.js`; её лицензия MIT сохранена рядом. `online.js` сам загружает библиотеку при первом открытии лобби, поэтому одиночная игра и игра на одном ПК работают без сетевого модуля.

Хозяин создаёт лобби, получает случайный шестизначный код и оставляет страницу открытой. Друг открывает эту же игру на своём компьютере и вводит код. Для обмена адресами используется бесплатный PeerJS Cloud; после подключения игровые данные передаются напрямую между браузерами. Никаких API-ключей и платного сервера не требуется. Код — временный адрес комнаты, а не учётная запись или средство защиты важных данных. В комнату допускается только один гость.

Игровой протокол управляется приложением: хозяин рассчитывает физику обоих огоньков, гость передаёт ввод, хозяин отправляет снимки состояния. Это исключает расхождение головоломок, таймеров, свечей и завершения уровня. Данные идут по надёжному каналу WebRTC. При переполнении сетевого буфера устаревшие кадры пропускаются, чтобы не накапливать задержку.

Нужен доступ к интернету и WebRTC. Некоторые корпоративные сети, VPN и симметричный NAT блокируют прямое соединение. Собственного TURN-сервера в проекте нет: в таких условиях игра сообщает об ошибке и предлагает сменить сеть или играть на одном ПК. Бесплатный внешний сервер сигналинга также может быть временно недоступен. Это реальная зависимость онлайн-режима, а не имитация сетевой игры.

API:

```js
import { OnlineSession } from './online.js';
const session = new OnlineSession({
  onStatus: message => {},
  onConnection: ({ role, code }) => {},
  onData: packet => {},
  onDisconnect: reason => {},
});
const { code } = await session.create(); // хозяин
// На втором ПК: await session.join(code)
session.send({ type: 'start', levelId: 1 });
session.close();
```

Официальные источники: [API Peer](https://peerjs.com/client/api/peer), [DataConnection](https://peerjs.com/client/api/data-connection), [PeerJS Cloud](https://peerjs.com/server/cloud), [ограничения сетей и TURN](https://peerjs.com/client/faq).
