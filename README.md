# Огонёк — пока горит свет

Браузерный 2D-паркур с пиксельной графикой. Донесите огонь до свечи, пока не иссякло тепло. Фон, платформы, персонажи и эффекты рисуются в Canvas, без тяжёлых изображений и игрового фреймворка.

## Самый простой запуск

Откройте **Огонёк.html** двойным щелчком. Это самостоятельная версия со всеми скриптами внутри. Интернет нужен только для сетевого лобби и необязательных веб-шрифтов.

Для разработки установленных библиотек не требуется: Node.js 18+ и команда `npm start`. Откройте http://localhost:4173. Источники игры находятся в `dist/` и готовы для любого статического HTTPS-хостинга.

## Что есть в игре

- 30 одиночных и 30 совместных уровней в трёх главах.
- Двойной прыжок, рывок, движущиеся и осыпающиеся платформы, скользкий лёд, грибы-пружины, вода, шипы, ветер и периодический дождь.
- Свечи сохраняют позицию и восстанавливают топливо. Золотые искры тоже дают тепло.
- В кооперативе свет зависит от расстояния между игроками. Парные печати нужно активировать одновременно. Открытые врата остаются открытыми.
- Игра на одном ПК и настоящее WebRTC-лобби с кодом из шести символов.
- После 30 совместных уровней открываются забеги на одинаковых маршрутах. При большом расстоянии экран разделяется; у каждого огонька своё финишное время.
- Три звезды: дойти до цели, уложиться в целевое время, собрать все искры без затухания. Результаты можно улучшать повторным прохождением.
- Вторая и третья главы требуют 18 и 40 звёзд соответственно. Прогресс одиночной и совместной кампании считается отдельно.
- После обеих кампаний открывается секретный эпилог. Нажмите на «огонёк» внизу страницы, чтобы вернуться к нему.
- Локальное сохранение, звук, пауза, полноэкранный режим и сенсорные кнопки первого игрока.

## Управление

| Действие | Первый игрок | Второй на одном ПК |
|---|---|---|
| Движение | A / D | ← / → |
| Двойной прыжок | W или пробел | ↑ |
| Рывок | Shift | Правый Ctrl |
| Пауза | Esc | Esc |
| Заново | R | R |
| Полный экран | F | F |

В онлайн-режиме каждый играет через A / D / пробел / Shift. Уровни выбирает создатель лобби. При паузе одного игрока останавливается вся игра.

## Сеть и сохранение

Сигналинг идёт через бесплатный сервис PeerJS, игровые данные передаются по прямому шифрованному WebRTC-соединению. Некоторые корпоративные сети и сложные NAT блокируют такое соединение; собственного TURN-сервера в проекте нет. Подробности и лицензия библиотеки — в `ONLINE.md`.

Прогресс хранится в браузере для текущего адреса игры. Между локальной, опубликованной и самостоятельной версиями он автоматически не переносится. Очистка данных сайта удаляет сохранение.

## Проверки

`npm run check` проверяет синтаксис. `npm test` проверяет физику, уникальность и достижимость карт, все позиции искр, головоломки, восстановление у свечей, связь, сетевой протокол, разблокировки и повреждённые сохранения. `node export-standalone.mjs` обновляет самостоятельный HTML после изменений.

Пиксельные игровые ассеты созданы программно. PeerJS 1.5.5 распространяется по MIT; его лицензия включена в `dist/vendor/`.
